# API RESTful com Node.js e MongoDB

Projeto que cria conexão com Banco de Dados, que neste caso é o MongoDB, e permite adicionar, buscar, editar e deletar itens.

### 📋 Pré-requisitos

É essencial que você tenha o ```Node.js``` em sua máquina para rodar a aplicação.

### 🔧 Instalação

1°- Faça um clone do repositório utilizando os comandos:
```
$git clone https://github.com/gabriel-cheng/api-restful-mongo
```

2°- Dentro do diretório clonado, instale as dependências necessárias para que a aplicação consiga ser executada utlizando o seguinte comando:
```
$npm install
```
3°- Ainda dentro do diretório, rode o seguinte comando para iniciar a aplicação:
```
$npm run server
```

### 📋 Portas de acesso

- API backend: < ```http://localhost:3000``` >
